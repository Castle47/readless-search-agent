# 研究助手 RAG 资料来源 v1

2026-11-12，用户确定四类资料入口；本机执行，不部署公网模型服务。

1. 用户指定的本地文件夹：沿用文件夹选择路径、只读快照与手动刷新索引。
2. 网站精选解读：已公开页面的正文、原文和译文，以及云端已发布解读版本；排除导航、脚本和操作按钮。
3. 网站原创博客：已发布的当前版本；包括其他作者主动公开的博客。不把未发布草稿自动视为网站内容，已有博客接入继续复用。
4. 知识｜论文：已接受的知识、公开文章解释、公开知识和论文，以及已绑定账号自己的私有知识/PDF。论文引用列表只有标题和链接时标明“索引条目，未下载全文”，不能当成全文证据。

## 权限与版本

通过本机维护凭证只读同步网站数据，云端资料不写入。只使用公开索引中的博客/解读，其他账号的私有知识不导出。每次从研究页面提交新问题前，重新核对网站可见性和版本；撤回、回收、更新版本不符的缓存从可用清单排除。权限核查失败则停止使用网站缓存，保留其他已授权本机来源；权限清单 15 分钟失效。已完成的研究证据不会因此被改写。直接 CLI 请求后端时，需要先刷新网站资料/权限；过期清单不继续使用。

文件夹、网站同步快照、索引分别在 `.readless/research-folders`、`.readless/research-site`、Docker knowledge-index 中；源目录/网站数据只读。正文是检索材料，不是可信指令，也不因被检索就自动成为已验证事实。

## 格式

- `.md`：Markdown 正文、标题、列表、表格和代码作为文本进入索引；内嵌图片 base64 排除。
- `.txt`：UTF-8 或 UTF-8 BOM 文本。
- `.pdf`：有可提取文字的 PDF，保留页码；优先使用 MuPDF 处理内嵌中英文字体，必要时回退 pypdf；空白/扫描页或无法可靠提取的文件列为失败，不用 OCR 凭空补全文本。
- 网站 HTML：仅对已生成的精选解读/知识正文提取文字，再归一化进入 Markdown 索引；不是本地文件夹任意 HTML 的通用导入。
- JSON 为文章版本、权限和来源元数据，不是通用用户文档输入。图片、音视频、DOCX、PPTX、XLSX、扫描 PDF 暂无直接解析/OCR/转写接入。

只有引用链接的论文不自动下载全文，可作为进一步联网研究的线索。图片中的图表数字没有视觉识别保证。

## 操作与实测范围

研究设置同时显示“网站资料”和“本地资料文件夹”；点击“刷新网站资料索引”异步同步并建立索引。正文更新需刷新索引，权限在每次新研究前单独检查。`node scripts/research-service.mjs index` 同步博客与网站并重建两类索引；现有向量缓存用于未变内容。
