# 研究助手：本地资料文件夹

入口：本机研究助手 → 研究设置 → 本地资料文件夹。输入文件夹完整路径，点击“添加并建立索引”；最多保存 10 个。显示“已就绪”后，后续本地或混合研究自动检索这些资料，与既有笔记库、ReadLess 博客结果一起按相关性选择。明确仅联网搜索的研究不读取本地库。

支持 Markdown、UTF-8 TXT、文字型 PDF，递归扫描子目录。文件变更后点击“刷新索引”；当前为手动快照更新，不宣称实时监控。扫描 PDF 无 OCR，解析失败显示未纳入原因。隐藏项、符号链接、node_modules、__pycache__ 排除。每目录最多 1000 份文件/256 MiB，单文件 50 MiB。

原文件只读。本机副本在 `.readless/research-folders/<目录 ID>/`；路径与作业状态在 `.readless/research-config/folders.json`，容器仅挂载副本为只读；向量仍由本机 Ollama 生成。命中片段会送给已配置的远程研究模型，页面在添加前说明。正文是来源材料，不是指令。移除目录立即从活动清单撤销，不再参与新检索，原文件不动，已有研究证据不改写。

部署展示版不显示入口，也不访问访客文件。HTTP 管理入口只允许本机与同源写请求，不能通过公网代理使用。

更新后需运行 `npm run research:restart` 重建研究容器并加载新增的只读挂载；向量模型未准备好时使用已有 `npm run research:provision`。失败或中断时不启用该目录，界面保留原因并支持刷新重试。
